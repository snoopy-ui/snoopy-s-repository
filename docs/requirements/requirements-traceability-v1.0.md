## 本轮最小闭环

选择同一脱敏任务和一名测试身份，依次完成：领取 → 必看视频完成/无视频跳过 → 服务端创建 20 分钟会话 → 作答 → 自评/修改 → 到时冻结 → 收件回执 → 云端/人工评价 → 教师反馈 → 修改重交。每一步都记录软件版本、任务哈希、规则/量规版本、时间、状态和证据位置。没有真实云端环境时，只能标为模拟演示。
