## 当前试点身份与任务边界

- 脱敏试点课程使用 `COURSE-DEMO-01`，任务示例为“数据清洗与结果说明”。正式课程名称、教师和评分量规仍待老师确认。
- 每个任务必须带稳定的 `school_id`、`course_id`、`course_offering_id`、`assignment_id`、`task_version` 和 `rubric_version`。姓名只能展示，不能作为主键。
- 任务发布必须声明 `audience`（学校、专业、年级、班级或成员 ID）、教师、发布范围、`open_at`、`close_at`、必看/可选材料、必交材料、视频与作业关系、帮助/例外/重测政策。
- 学生只能看到本人被分配的任务；老师只能访问获授权课程和班级。身份不确定、同名或跨校同学号冲突进入人工处理，不能静默合并。
- 任务发布后版本化。学生正式开始后锁定任务字段、量规和时限，后续编辑生成新 `task_version`，不能改写已开始会话。

## 视频完成与 20 分钟会话

- 视频是按任务声明的必看或可选材料。视频数量为 0 时，界面显示“无需下载/无需观看”，下载步骤标记完成，学生可以直接作答。
- 必看视频必须产生可信的完成事件：服务端保存视频、任务、学生、覆盖区间和完成时间；任意向前拖动、重复回看或单纯播放时长不能冒充完成。85%/90% 只能是待评审参数，不能直接当作统一“看完”政策。
- 对同一 `student_id + assignment_id + task_version`，首次可信完成事件至多创建一个 `attempt_id`；无视频任务以进入作答为等价起点，同样只能创建一个正式会话。会话写入 `started_at`，服务端计算 `deadline_at = started_at + 1200s`，正式有效区间为 `[started_at, deadline_at)`。
- 回看、重启、换设备、修改本机时间、自查重试和 AI 等待都不能重置或无限暂停期限。到期后冻结最后一个合法版本；晚到修改不能进入冻结快照，也不能通过新稿延长旧会话。

## 提交、评价和状态

推荐状态流转：

`assigned → learning → ready_to_start → in_progress → ai_waiting → frozen → pending_upload → received → pending_review → returned → resubmitted → published`

异常状态单独记录：`download_temp_failed`、`download_permanent_failed`、`check_pending_manual`、`upload_failed`、`evaluation_pending`、`appeal_hold`。异常状态必须提供下一步操作，不得伪装成“已提交”或“作业不合格”。

- `attempt_id` 标识一次限时作业会话，`revision_id` 标识会话内一个草稿/修改版本，`submission_id` 标识一次收件请求，`submission_version` 标识修改重交版本。
- 每轮自评、Codex 反馈、修改说明、附件清单和观看摘要都绑定 `revision_id`；冻结快照只读保存正文、笔记、自评、反馈、说明、材料哈希和版本关系。
- 网络重试或回执丢失沿用同一 `submission_id`；同 ID 的不同内容必须拒绝并记录冲突。修改重交使用新的 `submission_version`，旧版本、旧回执和老师意见保留。
- 自查通过、云端已收件、老师已通过是三个不同状态。云端评价只能读取冻结原件和可信量规；缺原件、哈希不符、无量规或无独立证据时进入“待复核”，不默认 100 分或 0 分。
- 老师可以人工复核并覆盖 AI 建议，但必须记录复核人、时间、结论、依据和覆盖理由。发布成绩后仍保留申诉和重测审计记录。

## 已确认的 A 裁定

### 文件命名（回应 E 的 K05）

任务导入只要求扩展名为 `.md` 或 `.markdown`，不把 `StudyCheck_*.md` 当作业务规则。系统可以建议命名约定，但不能拒绝合法的普通 Markdown 文件；`no-video-task.md` 被拒记为 Issue #8，交给 B 修复并由 E 复验。

### 版本（回应 E 的 K04）

安装包显示 v0.1.5 只能作为测试候选版本。正式发布必须同时具备发布记录、变更说明、稳定基线和 E 回归报告；旧 v0.1.4 清单不能代替 v0.1.5 清单。

### 自查服务故障（回应 E 的 K01）

自查服务不可用时默认进入 `check_pending_manual`，禁止自动提交和自动判定合格/不合格，学生仍可保存草稿。只有课程开启人工复核且老师记录复核人、时间、结论和理由后，才允许继续提交。

## 待老师/项目方确认

- 正式课程、教师、截止日期、迟交规则、量规维度和成绩发布范围。
- 多视频是全部必看后统一开始，还是按视频分段计时；倍速、后台播放和无障碍例外。
- 是否允许完整 AI 示例、独立解释题/变式题，以及 AI 故障补时或重测政策。
- 草稿云同步和附件补传窗口；重测次数及成绩采用规则；通知渠道和安静时间。
- 真实云端地址、认证方式、HTTPS、数据留存期限及备份 RPO/RTO。
- 正式作答设备范围；手机是否可作为 20 分钟作答设备。

在上述内容确认前，团队可以用脱敏样例和模拟服务开发，但必须将结果标为模拟，不能当作真实联调、正式评分或教学效果数据。
